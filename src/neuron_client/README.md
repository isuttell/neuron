# Neuron Client

A realtime chat application built with React, TypeScript, and Vite.

## Keyboard Shortcuts

### Audio Recording

- **Push-to-Talk**: Hold `Ctrl + Shift + .` to record audio while the keys are pressed
- **Toggle Recording**: Press `Ctrl + Shift + /` to start recording, press again to stop

### Other Features

The application also supports:

- Click-to-record using the microphone button
- File attachments
- Media playback
- And more...

## Development

This project uses:

- React 18 with TypeScript
- Vite for development and building
- Shadcn UI components
- Redux for state management
- Jest and React Testing Library for testing

### Getting Started

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run dev
```

3. Run tests:

```bash
npm test
```

4. Build for production:

```bash
npm run build
```
