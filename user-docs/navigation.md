# Navigation & Interface

This guide explains how to navigate Neuron and use its interface components effectively.

## Application Routes

Neuron is organized into distinct sections, each accessible through specific routes:

### Main Routes

- **Home** (`/`): The main entry point for starting conversations with personalities
- **Personalities** (`/personalities`): Browse and manage all available AI personalities
- **Thread View** (`/thread/:threadId`): Individual conversation spaces with AI personalities
- **Personality Edit** (`/personality/:personalityId/edit`): Configure and customize personality settings
- **Chat Rooms** (`/personality/:personalityId/room/:roomId`): Multi-user conversation spaces

### Additional Features

- **Scheduled** (`/scheduled`): View and manage scheduled tasks and prompts
- **Help** (`/help`): Comprehensive user guide and feature documentation
- **Privacy** (`/privacy`): Privacy policy and data handling information

## The Sidebar

The sidebar is your primary navigation tool, providing quick access to all major sections.

### Sidebar Components

#### Header Section
- **Dynamic Image**: Displays a generated image
- **Neuron Logo**: Click to return to the home page
- **Main Navigation**: Quick links to Home and Personalities

#### Content Section
- **Thread List**: Shows all your active conversations
- **Recent Threads**: Quick access to your most recent discussions
- **Thread Status**: Visual indicators for active, shared, and archived threads

#### Footer Section
- **User Profile**: Displays your profile picture and username
- **Dropdown Menu**: Click the chevron to access:
  - User information (name and email)
  - **Scheduled**: View scheduled tasks
  - **Help**: User documentation
  - **Privacy**: Privacy policy
  - **Logout**: Sign out of Neuron
