# Basic Usage

This guide covers the fundamental features and navigation of Neuron, helping you start conversations and manage your interactions with AI personalities.

## Getting Started

### The Home Page

When you log in to Neuron, you're presented with the home page featuring a central prompt input form. This is your starting point for all conversations.

**Key Controls:**

- **Personality Dropdown** (bottom left): Select from all personalities you have access to
- **Mode Toggle** (next to dropdown): Switch between Chat and Agent modes
  - **Chat Mode**: Enables multi-user conversations where you can collaborate with others
  - **Agent Mode**: Direct one-on-one interaction with the selected personality
- **Action Buttons** (bottom right):
  - **Submit**: Send your message
  - **Upload Files**: Attach documents, images, or other files for context
  - **Record Audio**: Capture voice input that will be transcribed and sent

### Starting a Conversation

1. Select your desired personality from the dropdown
2. Choose between Chat or Agent mode
3. Type your message or question in the prompt field
4. Optionally attach files or record audio
5. Submit your message

Once submitted, you'll be automatically redirected to the room/thread view where the AI's response will stream in real-time.

## Room/Thread View

After submitting your initial prompt, you enter the dedicated conversation space.

### Continuing the Conversation

The same controls from the home page now appear at the bottom of the thread view:
- Message input field for follow-up questions
- Personality selector (if you want to switch)
- Mode toggle
- File upload and audio recording options

Each message builds on the conversation context, allowing for deep, coherent discussions on your topic.

### Thread Management

In the top right corner of each thread page, you'll find actions to manage your conversation:

- **Manage Users**: Share the thread with other Neuron users for collaboration
- **Delete Thread**: Permanently remove the conversation

## Privacy and Sharing

### Default Privacy
By default, all rooms and threads you create are **private to you**. No other users can see or access your conversations unless you explicitly share them.

### Sharing Threads
To collaborate with others:
1. Click the actions menu in the top right corner
2. Select "Manage Users"
3. Choose which users by email to grant access
4. Shared users can view and participate in the conversation

### Shared Access
When you share a thread:
- Selected users can read the entire conversation history
- They can add their own messages
- In Chat mode, multiple users can interact simultaneously
- You maintain control and can revoke access at any time

## Modes Explained

### Agent Mode
- Direct interaction with a single personality
- Focused, one-on-one conversation
- Ideal for task-oriented work
- Personality maintains full context of your discussion

### Chat Mode
- Multi-user capable conversations
- Collaborative problem-solving
- Real-time interaction with other users
- Personality responds to all participants
- Rolling context

## Quick Tips

1. **Personality Selection**: Choose the right personality for your task - each has different capabilities and styles
2. **File Context**: Upload relevant documents at the start for better responses
3. **Voice Input**: Use audio recording for longer inputs or when typing is inconvenient
4. **Thread Organization**: Create separate threads for different projects or topics
5. **Collaboration**: Use Chat mode when you need input from team members
