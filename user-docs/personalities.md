# Personalities

Personalities are the heart of Neuron, defining how AI assistants interact with you. Each personality has its own set of instructions that shape everything from their communication style to their specialized capabilities.

## What Are Personalities?

A personality in Neuron is a customized AI assistant with specific characteristics, behaviors, and capabilities. You can configure personalities to:

- **Set Communication Style**: Define the voice, tone, and response length
- **Assign Roles**: Create specialized assistants for specific tasks or domains
- **Enable Roleplay**: Design characters with unique backgrounds and behaviors
- **Configure Tools**: Select which capabilities the personality can access

Whether you need a technical assistant, a creative writing partner, or a specialized expert, personalities let you tailor the AI experience to your exact needs.

## Creating a Personality

Creating a new personality is straightforward:

1. **Navigate to the Personalities Page**: Access the personalities section from the main navigation
2. **Click the Plus Icon**: Located in the top right corner of the page
3. **Describe Your Vision**: A modal will open where you can input a general description of what you want your personality to be
4. **Auto-Generation**: Neuron will generate a first draft of your personality based on your description
5. **Review and Refine**: The generated personality is ready to use immediately, or you can edit it to perfect the details

## Editing and Customizing

Once created, you can fully customize your personality through the edit page:

### Available Customizations

- **Name**: Give your personality a distinctive identity
- **Tool Access**: Select which tools and capabilities the personality can use (image generation, web search, code execution, etc.)
- **Context**: Define the personality's background knowledge and behavior patterns
- **System Prompt**: Fine-tune the exact instructions that guide the personality's responses

### Accessing the Edit Page

Click on any personality from the personalities page to open its edit interface. Here you'll find all customization options organized in an intuitive layout.

### Uploading Documents to Memory

To enhance a personality's knowledge base:

1. **Navigate to the Edit Personality Page**
2. **Click the Upload File Icon**: Located in the top right corner of the page
3. **Select Files**: Choose documents you want to add to the personality's memory
4. **Upload Complete**: Once uploaded, the documents will appear in the list of available tool sets

This allows the personality to reference and use information from your uploaded documents in conversations.

## Managing Personalities

### Top Right Controls

The personality edit page provides three key management options in the top right corner:

- **Upload Files Button**: Add documents to the personality's memory (file icon)
- **Manage Users Button**: Share the personality with other users by email
- **Delete Personality Button**: Permanently remove the personality

### Sharing
Share your personalities with other Neuron users to collaborate or let others benefit from your custom assistants. The Manage Users dialog allows you to:
- Add users by email address
- View who currently has access
- Remove user access when needed

### Deleting
Remove personalities you no longer need via the delete button. Deletion is permanent, so make sure you've saved any important configuration details before removing a personality.

## Best Practices

### Clear Instructions
Be specific about the personality's role, knowledge domain, and communication style. The more detailed your instructions, the more consistent the personality's behavior.

### Tool Selection
Only enable tools that are relevant to the personality's purpose. This keeps interactions focused and prevents unnecessary complexity.

### Iterative Refinement
Start with the auto-generated personality and refine it through actual use. Pay attention to responses and adjust the instructions to better match your expectations.

### Specialized vs. General
Consider whether you need a specialized expert or a general assistant. Specialized personalities excel in their domains, while general ones offer broader flexibility.

## Example Use Cases

- **Creative Writer**: Configured for storytelling, worldbuilding, and creative collaboration

- **Language Tutor**: Designed to help with language learning and practice
- **Project Manager**: Organized personality for task tracking and project coordination
